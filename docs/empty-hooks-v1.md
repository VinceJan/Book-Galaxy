# v1 空书页钩子说明

运行时目录在抽取改进后仍有 **87** 本 `hook` 为空（此前 108）。
`book.hook` 必须是中文维基导语的**原句片段**；导语过薄或只剩出版/别名噪音时，诚实留空，不由模型编造。

## 抽取改动（`scripts/lib/book-hook.mjs`）

- 组合句被拒后：优先单独采用带 CONTENT_SIGNAL 的内容句，**即使**以「该/此/这/本」起首。
- CONTENT_SIGNAL 增补：`探究` `记载` `透过` `反映`。
- ANAPHORA：`这些/上述/前述` 仅在句首计为回指，避免误伤「认为这些……」。
- 别名剥离：覆盖「另译为 / 汉译为 / 台湾译为」等；纯译名罗列仍留空。

## 仍为空的原因分布
