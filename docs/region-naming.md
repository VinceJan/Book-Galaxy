# 星海地名（星团命名）

星海被离线划分为 12 个区域：在语义布局的三维坐标上做 k-means（k=12，确定性的最远点初始化，`scripts/lib/regions.mjs`）。每个区域以其**中心书（medoid）**的 Wikidata Q 号为键，在 `data/regions/names.json` 中手工命名。命名规则如下：

- **地名（主名，C 体）**：显示在星图上，2–4 字，地貌后缀表达密度：高原/台地/谷 = 稠密，海峡/海岸/河湾/渡口 = 过渡，群岛/列岛/平原/沙洲/孤岛 = 稀疏。
- **问句（B 体）**：只在打开区域（馆员来信）时出现，是这片星在问的问题。
- 名称必须对得上区域里真实的主题和代表作；`npm run build:data:runtime` 会在区域缺名或名称过期时报错。

## 缩放层级（`src/galaxy/regionLabelLayout.ts`）

| 层级 | 相机距离 d | 显示 | 上限（桌面/手机） |
|---|---|---|---|
| L0 全景 | ≥160 | 地名 | 6 / 4 |
| L1 中景 | 100–160 | 地名 + 副题 + 书星数 | 8 / 5 |
| L2 近景 | 72–100 | 地名，透明度 30%（所在区域 60%） | 8 / 5 |
| L3 贴近 | <72 或已打开一本书 | 只显示所在区域的地名（淡） | 1 |

优先级：所在区域 > 规模 > 离屏幕中心近；标签之间留 12/10px 间距；不进入顶栏、底栏和航迹栏区域；只整块显示；层级切换有 ±8% 滞回。二级子团命名留待后续。
