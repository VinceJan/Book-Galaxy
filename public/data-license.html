BOOKSHELF GALAXY / DATA PROVENANCE

每颗书星，
都有来处。

这片星海把开放书目、中文百科导语与算法生成的空间布局编织在一起。本页说明什么来自哪里、经过了什么处理，以及哪些权利不能被项目代为许诺。

中文内容

中文主标题与作品摘要主要取自中文维基百科的对应作品页，按 zh-cn 变体读取，清理空白并在句末附近截取。每本书都保留页面链接及构建时使用的固定修订链接。

这些文本依据 CC BY-SA 4.0 使用；贡献者名单以对应页面的修订历史为准。技术性整理属于对来源文本的改编，继续适用相同方式共享要求。

结构化书目

作者、年代、语言、地域、作品类型、外部标识等结构化字段来自 Wikidata，并在每条记录中保留作品 Q-id 回链。Wikidata 的结构化数据按 CC0 1.0 发布。

语义坐标、密度、星体视觉参数和路线分数由本项目根据已署名字段离线计算；它们是探索性推断，不是文学史事实或来源机构背书。

开放书影

一般记录在存在可靠 Open Library work 标识时，从 Covers 服务远程加载书影并链接回 work 页面。六条人工批准覆盖（Q607112、Q753894、Q70784、Q180736、Q1760054、Q3140506）则链接到对应的 exact Edition 页面：界面显示 M 派生图，机器可读的 coverAsset 保留审计过的 L 图、权利复核与生命周期。仓库不批量复制这些图片。

公开可访问的封面 URL 不等于 CC0 授权。封面仍可能受原始出版物或权利人的条款约束；无可靠书影时，界面只生成明确的文字藏书牌，不伪造真实封面。封面隔离或移除可通过 项目移除表单提出。

逐书核验

发布数据旁附有机器可读归属清单。它逐书列出中文维基页面、固定修订、Wikidata 实体与封面来源，并绑定当前 catalog 的 SHA-256。
